TASK: Cross-platform integration and spatial deconvolution.

Cohort manifest: {{cohort_manifest}}
Deconvolution reference: {{reference_atlas}}
ST platforms in cohort: {{st_platforms}}

Write the R pipeline (Seurat v5 + harmony + spacexr/RCTD) and state, before any code, the
three decisions that determine whether the output is interpretable:

1. QC thresholds are per-tissue, not global. Kidney, liver and heart carry high baseline
   mitochondrial content; a flat 10% cut deletes real cells. Derive thresholds per sample
   (e.g. MAD-based) and log both the threshold and the number of cells lost.
2. Batch is confounded with cancer type in a pan-cancer cohort. Integration that removes
   "batch" can remove the biology. Correct within cancer type over patient, then align
   cancer types only at the level of shared cell-type labels -- and say explicitly which
   downstream claims survive that choice.
3. Deconvolution of a rare cell type is the weak link. NK cells are typically 0.5-3% of a
   tumor; a 55 um Visium spot holds 1-10 cells. RCTD full-mode weights for a rare type are
   dominated by reference-profile similarity to abundant types (NK vs CD8 T is the specific
   failure). Required: (a) run RCTD in doublet mode as well as full mode and report the
   agreement; (b) benchmark against held-out marker genes AND against a simulated spot
   mixture built from the reference; (c) emit a per-cell-type reliability flag, and make
   NK-specific claims only on single-cell-resolution platforms (Xenium/CosMx/MERFISH),
   using Visium for niche context only.

Then the code: QC + DoubletFinder, Harmony (or scVI via reticulate), RCTD/cell2location,
and the benchmark. Modular functions, explicit logging, restartable from intermediate RDS.
