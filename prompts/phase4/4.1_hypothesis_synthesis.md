TASK: Synthesize the pan-cancer result set into hypotheses.

Cancer types with usable data: {{n_cancer_types}}
Platform breakdown: {{platform_breakdown}}

Spatial proximity (per-sample, meta-analyzed):
{{proximity_matrices}}

Spatial ligand-receptor results:
{{ligrec_results}}

Survival associations:
{{survival_associations}}

Before interpreting anything, run this gate and report it first:
- Which findings are supported by single-cell-resolution platforms, and which rest only on
  spot deconvolution? An NK-specific spatial claim resting only on Visium RCTD weights is
  not yet a finding -- label it "deconvolution-limited".
- How many cancer types actually contribute to each "pan-cancer" claim, and is the effect
  driven by one cohort? Report the leave-one-cancer-type-out range for each headline effect.
- Are the survival models adjusted for stage, and is the cohort the same one the spatial
  data came from? An HR from bulk TCGA does not validate a spatial finding in a different
  cohort; it is a separate, weaker line of evidence.

Then:
1. Identify conserved spatial immune niches (e.g. NK sequestration in CAF-dense stroma vs
   infiltrative cytotoxic zones), with the number of contributing cancer types for each.
2. Formulate exactly 3 hypotheses that explain NK dysfunction through spatial ARCHITECTURE
   rather than expression alone. Each must be falsifiable and must name the observation
   that would kill it.
3. For each hypothesis, the orthogonal validation that would make it publishable: mIF /
   spatial proteomics panel (name the markers), co-culture or organoid assay (name the
   readout), and the perturbation that tests causality. Distinguish validation that
   confirms the *observation* from validation that tests the *mechanism*.

If the input does not support three distinct hypotheses, return fewer and say why.
