ROLE ADDENDUM: Lead Computational Immunologist.

TASK: Isolate, subcluster, and spatially map NK cells.
Input: {{adata_path}} (platform: {{platform}})
Anchor structures for distance profiling: {{anchor_classes}}

1. NK identity. Positive: NCAM1, KLRD1, KLRF1, NCR1, FCGR3A, NKG7, GNLY, PRF1, CD160.
   Negative: CD3D, CD3E, CD3G, TRAC, TRBC1/2, CD14, LYZ.
   Note the three confusions that must be handled explicitly, not assumed away:
   NKT and gamma-delta T cells (TRAC/TRDC), ILC1 (EOMES-low, absent PRF1), and monocytes
   (FCGR3A+ but LYZ+). KLRF1 and NCR1 are the discriminating markers; FCGR3A alone is not.
   Emit an ambiguity report: how many barcodes were dropped as CD3+, how many as
   double-positive, and the NK fraction per sample.
2. Subclustering into Cytotoxic (PRF1, GZMB, FGFBP2), Dysfunctional (HAVCR2, LAG3, TIGIT,
   KLRC1), Resident (ITGA1, CD69, ZNF683), Cytokine-producing (IFNG, TNF, XCL1). Score
   programs rather than hard-gating; leave an explicitly labelled `unassigned` state and
   report cluster stability (bootstrap ARI) -- do not report a state count that is unstable
   to resolution choice.
3. Spatial proximity: per-cell distance to the nearest instance of each anchor class, via
   KD-tree, computed PER SECTION in physical units (um), never in pixel or array units.
   Report the distance distribution per sample, then aggregate across samples by
   random-effects meta-analysis. Normalize against a within-section null that preserves
   tissue geometry (rotate/torus-shift the NK label field inside the tissue mask).
4. Neighborhood enrichment (`sq.gr.spatial_neighbors` + `sq.gr.nhood_enrichment`) and
   ligand-receptor testing with `sq.gr.ligrec` (note: `squidpy.gr.ligand_receptor_score`
   does not exist). Candidate axes: HLA-E - KLRC1, PVR/NECTIN2 - TIGIT, TGFB1 - TGFBR2,
   LGALS9 - HAVCR2, CD47 - SIRPA. State explicitly that co-expression in adjacent
   neighborhoods is a hypothesis about signalling, not evidence of it.

Output: a Scanpy/Squidpy module with the above as composable functions, each returning a
tidy per-sample dataframe suitable for the meta-analysis layer.
